## <img src="https://api.iconify.design/lucide:wifi.svg?color=%23f5d98a&width=26" align="top"> 99 % hors connexion

Toutes les données et images du jeu sont **embarquées** : la quasi-totalité d'Eliadex fonctionne **sans Internet**.
Seule exception — les **Rotations du jour** (donjons du jour, Modulox, Néo-Boss, Almanax), tirées d'un calendrier communautaire mis à jour en ligne. Hors connexion, cette section affiche simplement un message dédié.
